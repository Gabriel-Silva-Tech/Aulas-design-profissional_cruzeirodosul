## Codigo em linha e blocos 
Use a crase para destacar um comando ou trecho curto no meio de uma frase.

O comando `git status` mostra o estado atual do repositório

O comando `git status .` adiciona os arquivos modificados à *Staging area*. 

O comando `git commit -m "Texto com a descrição do que foi feito no código "` registra as alterações em uma mensagem. 

O comando ` git push origin main` sobre as alterações para a nuvem. 

```
git status
git add . 
git commit -m "Texto com a descrição do que foi implementado"
git push origin main 
 
```
